# Android v2

La app Android usa exclusivamente la API HTTP del servidor. Configura IP, puerto y token en ajustes; la pantalla Imagen envía el  a  y muestra los bytes recibidos. La pantalla Orden envía texto y desplazamiento a . No contiene cifrado local. Para crear el proyecto en Android Studio usa Kotlin, minSdk 26, target 35 y OkHttp 4.12.
