# Manual de Unity 6.3

Crea un proyecto 2D con Unity 6000.3.x y abre la escena Game. El enemigo avanza por saltos hacia la puerta. Si entra en el trigger, se descuenta una vida. Descifra cada frase César y pulsa Validar. Una respuesta correcta suma puntos; un fallo acerca al enemigo. Hay estados EnCurso, Victoria y Derrota, tres rondas, dificultad, pistas y reinicio.

La ejecución de PlayMode, capturas, APK y cobertura requieren Unity 6.3 con licencia. Hasta entonces se conserva PENDIENTE-HUMANO.
