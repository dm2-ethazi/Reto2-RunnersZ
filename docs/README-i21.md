# Rama feature/i21-cross-review

## Objetivo
Documentar la revisión cruzada de las entregas de Jairo y los criterios
necesarios para mover una tarjeta a Hecho.

## Criterios
- La PR pertenece a una sola tarea y está enlazada con su issue.
- La rama tiene README o documentación de uso.
- Las pruebas ejecutadas tienen salida real guardada.
- CI debe estar verde antes de integrar.
- Alain debe revisar la PR.
- Las pruebas de Android, Unity y dispositivo real se marcan
  PENDIENTE-HUMANO mientras falten SDK, Unity/licencia o dispositivo.

## Estado actual
Las PR de Android y Unity están abiertas y en revisión. El tablero no debe
marcar ninguna como Hecho solo por tener commits publicados.
