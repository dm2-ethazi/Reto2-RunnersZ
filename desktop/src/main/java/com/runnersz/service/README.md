# Servicios del cliente

Configura servidor y token en Ajustes, prueba la conexión y usa AES o Vigenère. ApiClient procesa HTTP; FileOperationService protege el original; FileService escribe con temporal; SettingsStore conserva ajustes. Los errores conocidos mantienen claves de I18n y se muestran en el idioma seleccionado. Utiliza Java estándar; ningún servicio importa JavaFX ni cifra localmente. Responde al contrato §3, §5.4 y §7.2.
